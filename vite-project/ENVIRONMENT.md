# Environment Variables Configuration

This document outlines the environment variables used in the `vite-project`.

## Environment Variables

### Database Configuration
- **DATABASE_URL**: The complete URL for the database connection, used by SQLAlchemy.
- **DATABASE_USER**: The username for the database connection.
- **DATABASE_PASSWORD**: The password for the database connection.
- **DATABASE_HOST**: The hostname for the database server.
- **DATABASE_PORT**: The port number for the database server.
- **DATABASE_NAME**: The database name to connect to.

### API Configuration
- **API_BASE_URL**: The base URL for API requests.

### Authentication
- **JWT_SECRET**: Secret key for JWT authentication.

Please ensure that placeholders are replaced with actual values as required for your environment.
